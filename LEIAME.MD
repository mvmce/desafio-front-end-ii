\## 📄 Estrutura do site



O projeto é composto por três páginas principais:



| Página | Função |

|--------|--------|

| \*\*index.html\*\* | Página inicial — apresenta o autor e um botão para acessar o formulário. |

| \*\*form.html\*\* | Formulário com validação de campos: nome, sobrenome, email e idade. |

| \*\*confirmation.html\*\* | Mostra os dados digitados e permite confirmar ou editar. Ao confirmar, salva os dados em `data.json` e redireciona para a página inicial. |



---



\## 🧩 Funcionalidades



✅ Validação completa dos campos:  

\- \*\*Nome\*\* e \*\*Sobrenome:\*\* 3 a 50 caracteres.  

\- \*\*Email:\*\* Validação via expressão regular (regex).  

\- \*\*Idade:\*\* Número inteiro positivo menor que 120.



✅ Salvamento de dados em `data.json` via JavaScript.  

✅ Redirecionamento automático após confirmação.  

✅ Estilo moderno, elegante e responsivo (com paleta azul petróleo e dourado).  

✅ Sem dependências externas — puro HTML, CSS e JS.
